<h1>LangSwitcher</h1>
Максимально простая но полезная утилита для переключения раскладки и ввода в Windows (русский\английский)


Возможности:

- Переключение введенного текста в нужную раскладку
- Переключение выделеного текста в нужную раскладку

Внимание:

- Переключение языка происходит при двойном нажатии на кнопку <b>Ctrl</b>.
- Для добавления звукового эффекта нужно заменить switch.wav на свой файл звука.
- Приложение не собирает никакие данные.
