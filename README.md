Программа для переключения раскладки и ввода в виндовс (русский\английский)

Переключение языка происходит при двойном нажатии на кнопку Ctrl

Для добавления звукового эффекта нужно заменить switch.wav на свой файл звука


Максимально простая но полезная утилита которая не решает за пользователя когда стоит переключать раскладку а позволяет делать это самому.
