<h1>LangSwitcher</h1>
Максимально простая но полезная утилита для переключения раскладки и ввода в Windows (русский\английский)

Философия приложения такова, что оно должно заменить службу виндовс которая должна изначально быть встроена в систему.

Но из за того что Microsoft не заботит сущуствование других раскладок помимо английской, такой службы нет.

Переключение раскладки происходит исключительно по осознанной команде пользователя. Нет никаких иконок в трее.

<br>

<b>Возможности:</b>

- Переключение `введенного` текста в нужную раскладку
- Переключение `выделеного` текста в нужную раскладку


<b>Внимание:</b>

- Переключение языка происходит при двойном нажатии на кнопку `Ctrl`.
- Для принудительной активации смены раскладки нужно выделить текст с зажатым `Ctrl`.
- Приложение полностью автономно и не собирает персональные данные.
- Для закрытия приложения его необходимо повторно открыть и выбрать "Остановить" (Либо завершить процесс)

Доп. комментарий:

>Приложение изначально расчитано только на пользователей с 2 раскладками, русской\английской. Возможно в дальнейшем будет расширено под любую кириллицу\латиницу, но так же подразумевая только 2 раскладки, работа с 3 расскладками пока не планируется, так как не представляю как это лучше всего реализовать.
