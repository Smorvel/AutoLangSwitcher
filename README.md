<h1>LangSwitcher</h1>
Максимально простая но полезная утилита для переключения раскладки и ввода в Windows (кириллица\латиница)

Философия приложения такова, что оно должно заменить службу виндовс которая должна изначально быть встроена в систему.

Но из за того что Microsoft не заботит сущуствование других раскладок помимо латинских, такой службы нет.

Переключение раскладки происходит исключительно по осознанной команде пользователя. Нет никаких иконок в трее, установщиков и прочего мусора.
<br>

[Скачать](https://github.com/Smorvel/LangSwitcher/releases/latest)

<br>

<b>Возможности:</b>

- Переключение `введенного` текста в нужную раскладку
- Переключение `выделеного` текста в нужную раскладку


<b>Внимание:</b>

- Переключение языка происходит при двойном нажатии на кнопку `Ctrl`.
- Для принудительной активации смены раскладки нужно выделить текст с зажатым `Ctrl`.
- Приложение полностью автономно и не собирает персональные данные.
- Для закрытия приложения его необходимо повторно открыть и выбрать "Остановить" (Либо завершить процесс)
- Приложение пока не умеет добавлять себя в автозагрузку, по этому надо в ручную закинуть например в `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- Чтобы приложение работало с другими приложениями запущенными от имени админа, его так же нужно запустить с правами администратора.

Доп. комментарий:

>Приложение изначально расчитано только на пользователей с 2 раскладками. Если у пользователя больше 2 раскладок, то приоритет все так же остается только на 2 раскладках, и чтобы переключить на след. кириличесскую или латинскую раскладку, нужно после нажатия клавиши вызова конвертации, нажать ее снова, тогда акцент будет смещен например с русской на украинскую. Рекуомендую использовать данное приложение именно с 2 раскладками.
